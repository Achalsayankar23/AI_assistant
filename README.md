# 🤖 Aura – AI Powered Desktop Assistant

Aura is a Python-based AI desktop assistant that automates daily tasks such as
opening applications, searching the web, playing YouTube videos, generating
content using AI, and executing system commands.

---

## 🚀 Features
- 🔊 Voice & text-based commands
- 🧠 AI-powered content generation (Groq API)
- 🌐 Google & YouTube search automation
- 🖥 Open & close desktop applications
- ⚡ Fast async task execution

---

## 🛠 Tech Stack
- Python 3.10
- Groq LLM API
- asyncio
- PyQt5
- Selenium
- BeautifulSoup
- dotenv
